# 项目说明与对话整理

记录日期：2026-10-08（北京时间）。

## 一、我们已经确认的信息

你希望了解 AI Agent / AI 应用开发工程师的条件，并进一步开始实际项目。你有三年前端开发经验，主要使用 Vue 和 React；写过 Node.js，但没有在实际后端项目中使用。

因此，学习路线从已有的前端能力出发，补齐后端、模型调用、知识库检索、任务执行、评测与部署。无需先学完 Python 才开始；以后根据岗位或功能需要补充 Python。

你要求新建独立文件夹统一管理，并将对话整理成能看懂的中文项目文档，开发每一步都同步记录。项目目录为 D:\zhxzzz\team-knowledge-assistant。

## 二、最终产品是什么

产品名：团队知识库助手。

用户登录后，可以上传团队文档、通过自然语言提问，获得附带原文出处的回答。后续助手还能调用业务工具，完成查询、生成报告或创建待办等具体任务。

典型使用场景：新同事问“报销需要哪些材料”，系统检索已上传的报销制度，给出回答并显示依据。没有相关资料时明确说明资料不足，不把猜测当作制度。

## 三、技术选择

| 技术 | 在项目中负责什么 | 选择理由 |
| --- | --- | --- |
| Vue 3 | 页面、交互、状态展示 | 复用已有前端经验；本项目先选择 Vue |
| TypeScript | 前后端类型检查 | 降低参数和数据结构出错的概率 |
| Vite | 前端开发与构建 | 启动快，开发代理配置简单 |
| Node.js + Fastify | API、业务逻辑、模型调用 | 用熟悉的语言学习后端；Fastify 便于直接测试接口 |
| PostgreSQL | 用户、会话、文档和任务数据 | 练习真实数据库与关系建模；后续按需加 pgvector |
| 模型 SDK | 服务端调用模型 | 提供对话、流式输出与工具调用，具体供应商后续确定 |

React 是你可以复用的技能，但当前项目只维护一套 Vue 前端，以便集中完成业务流程。尚未选择模型供应商，不依赖个人现有账号或密钥。

## 四、你要建立的能力

1. 写一个可部署的 Node.js 后端，并理解鉴权、数据库、日志和错误处理。
2. 在服务端接入模型，在前端展示流式输出、取消和失败状态。
3. 实现 RAG：先检索文档，再让模型基于检索结果回答。
4. 实现工具调用与多步执行，处理权限、确认、超时和失败。
5. 用固定问题衡量效果，记录耗时、费用和失败原因。
6. 最终交付代码、演示、部署说明与能讲清楚的项目案例。

## 五、文档如何持续更新

每个步骤都记录目标、关键知识、代码位置、验证方式、实际结果和下一步。每次功能修改同步维护进度和运行说明。后续开发默认遵循根目录 AGENTS.md 中的约定。

“实时更新”指实际开发时随步骤同步写入文档；对话结束后不会自动在后台持续开发。
