# 知识文档删除

在“我的知识文档”列表中点击“删除”，确认后会删除该文档及其分段。列表立即刷新，当前搜索结果里属于该文档的片段也会消失。

## 为什么需要后端校验

页面上的按钮只方便操作，不能充当权限控制。删除接口 DELETE /api/documents/:id 首先确认用户已登录，然后用文档编号和当前用户编号一起定位记录。其他人的文档与不存在的文档统一返回 404；无效编号返回 400。

数据库的 document_chunks.document_id 外键设置了级联删除，因此删掉文档时片段一起删除，后续检索不会再命中这些内容。已经生成的问答保有独立保存的来源快照，因此旧回答仍可解释当时依据的资料；删除文档并非清除所有历史引用。

## 本地验证

先运行 npm run db:local 并保持数据库终端打开，再在另一个终端依次运行 npm run typecheck、npm test、npm run test:db、npm run build。

数据库测试会创建临时用户和文档，并在结束时清理。2026 年 11 月 13 日执行结果为普通接口测试 1/1、数据库集成测试 5/5、类型检查及构建通过。页面删除交互尚未在浏览器人工验收。
