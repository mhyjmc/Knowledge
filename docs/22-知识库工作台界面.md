# 知识库工作台界面

本轮使用 frontend-design 技能重新整理页面。目标是让第一次使用的人先看到“导入资料 → 查看出处 → 确认待办”的实际路径，再进入对应功能；顶部介绍不再占据主要操作区，侧栏按钮可以跳转到真实页面位置。

## 界面如何使用

1. 登录后在“知识文档”里查看资料目录，选择文件或粘贴正文；已有文档可编辑或删除。
2. 在同一区域先检索原文片段，再到“智能问答”选择文档问答，展开回答下方的来源。
3. 在“任务助手”生成待办草稿，检查后确认创建，执行记录会保留。

未登录时点击受保护的导航入口会跳到账号页；登录后返回原目标页。手机宽度下侧栏改为横向导航，文档目录与编辑区改为单列。按钮、输入框和来源展开保留键盘焦点样式；系统要求减少动态效果时，导航滚动不使用平滑动画。

## 视觉取舍

2026 年 11 月 13 日根据用户要求改为蓝白主题：深蓝（#183b60）用于导航与标题，明蓝（#1c62a7）用于主要按钮，冷白（#f5f9fd）用于页面底色，白色用于表单与内容面，浅蓝线（#cddeec）分隔资料与表单。删除和错误继续使用红色语义提示。主视觉聚焦“有出处的答案”，资料目录以连续列表呈现，问答区按会话与消息分层，待办区把待确认动作放在记录旁边。

正文、按钮、辅助文字和导航的颜色对比度分别约为 10.8:1、6.3:1、4.6:1 和 7.8:1。蓝白主题覆盖桌面与 390px CSS 视口。

## 验证边界

真实浏览器使用 390px CSS 视口验证：访客进入文档路由跳转账号，注册并登录后返回文档页；新建和编辑文档、切换问答与待办、刷新后恢复会话、退出后受保护路由重定向均通过。页面 `scrollWidth=390`，没有横向溢出。临时账号已清理。此验收覆盖页面主要路径，不代表所有手机设备或所有视觉细节均经人工检查。完整代码检查结果见开发进度。
