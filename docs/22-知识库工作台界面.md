# 知识库工作台界面

本轮使用 frontend-design 技能重新整理页面。目标是让第一次使用的人先看到“导入资料 → 查看出处 → 确认待办”的实际路径，再进入对应功能；顶部介绍不再占据主要操作区，侧栏按钮可以跳转到真实页面位置。

## 界面如何使用

1. 登录后在“知识文档”里查看资料目录，选择文件或粘贴正文；已有文档可编辑或删除。
2. 在同一区域先检索原文片段，再到“智能问答”选择文档问答，展开回答下方的来源。
3. 在“任务助手”生成待办草稿，检查后确认创建，执行记录会保留。

未登录时点击受保护的导航入口会跳到账号区。手机宽度下侧栏改为横向导航，文档目录与编辑区改为单列。按钮、输入框和来源展开保留键盘焦点样式；系统要求减少动态效果时，导航滚动不使用平滑动画。

## 视觉取舍

使用深青色作为导航和主要文字，冷白作为操作背景，浅线分隔资料与表单。亮绿只用于少量状态提示。主视觉聚焦“有出处的答案”，资料目录以连续列表呈现，问答区按会话与消息分层，待办区把待确认动作放在记录旁边。

## 验证边界

源码通过 TypeScript 检查、普通接口测试和生产构建；桌面访客视图与无头浏览器支持的 436px 窗口访客视图已截图复查，顶部导航与账号卡片未见裁切。无头浏览器保存的 390px 手机截图实际按 436px CSS 视口排版，因工具裁切不作为真实 390px 手机视觉验收。登录后的文档编辑、问答和待办页面已通过类型检查及相关数据库行为测试，尚未在浏览器里人工逐项点击验收。
