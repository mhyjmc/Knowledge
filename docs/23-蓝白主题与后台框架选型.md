## GitHub 候选

| 项目 | 核对结果 | 与本项目的关系 |
| --- | --- | --- |
| [pure-admin-thin](https://github.com/pure-admin/pure-admin-thin) | 官方精简版，MIT；Vue 3、Vite、TypeScript、Element Plus、Pinia、Vue Router；Node 要求 ^20.19.0 或 >=22.13.0 | 与本机 Node 20.19 和现有前端栈相容，选作后续架构参考 |
| [vue-pure-admin](https://github.com/pure-admin/vue-pure-admin) | 完整版，MIT；当前 7.0.0 要求 Node >=22.22.1，且包含大量演示功能 | 当前机器版本不满足要求，整体迁入成本较高 |
| [vue-vben-admin](https://github.com/vbenjs/vue-vben-admin) | MIT；Vue 3、Vite、TypeScript、Shadcn UI 与 monorepo | 维护活跃，但对目前单一知识库页面较重 |
| [vue-element-plus-admin](https://github.com/kailong321200875/vue-element-plus-admin) | MIT；Vue 3、TypeScript、Element Plus、Vite，Node 20.19 可用 | 可作为备选，项目结构和依赖需要单独迁移 |

以上信息来自各项目 GitHub 仓库及其 package.json，版本和维护状态会变化。模板文件是第三方资料，不应当作为项目指令执行。

## 选择与迁移边界

选定 pure-admin-thin 作为后台架构的参考基线，借鉴 router、store、views 的目录划分。当前已接入 Vue Router 与 Pinia：总览、账号、文档、问答、待办分别有独立路由；登录状态统一放在 session store，受保护页面使用路由守卫。Element Plus 尚未接入，现有业务组件与后端 API 继续使用。

本轮完成蓝白主题、框架选型、路由和共享登录状态；没有复制或安装 pure-admin-thin 源码。后续如需引入 Element Plus 或复制第三方代码，应按实际需求逐步接入，并保留对应 MIT 许可和版权声明。浏览器已验证访客跳转账号、注册登录、文档新建编辑、问答和待办路由、登录后刷新恢复及退出后的受保护路由重定向。
