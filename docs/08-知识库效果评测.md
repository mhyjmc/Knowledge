# 知识库效果评测

## 为什么这一步需要评测

“模型能回答”只是链路可用。知识库还要能找到正确资料、在资料不足时拒绝编造，并且不能看到别人的资料。固定题库就像前端的回归测试：以后改检索、提示词或模型，仍使用相同题目来比较效果。

本步没有增加新的页面功能，而是建立可运行、可留存的效果基线。

## 如何运行

在项目根目录打开 PowerShell，先保持 PostgreSQL 运行：

```powershell
Set-Location D:\zhxzzz\team-knowledge-assistant
npm run eval
```

这是离线评测：使用真实本地 PostgreSQL 与应用接口，不请求模型。不要求网页或开发服务器正在运行；脚本自行创建应用实例并通过 `app.inject` 调用接口，所以不覆盖浏览器交互、网络代理或实际流式渲染。

需要验证当前模型时运行：

```powershell
npm run eval:live
```

真实模式读取服务端 .env，最多调用三次模型，按顺序执行，不自动重试。每次沿用项目的 120 秒超时与输出上限。会消耗供应商额度；网页无需操作。没有命中资料的第四道问答由服务端直接拒答，不调用模型。

结果存入 `docs/evaluations/`：Markdown 供阅读，JSON 保留详细资料快照、答案、状态、耗时和供应商返回用量。文件时间采用 UTC，北京时间为 UTC 加 8 小时。脚本不输出密钥、密码或登录 Cookie。

脚本创建两名随机临时用户，通过真实注册、登录和文档接口准备合成数据，结束后按本轮用户 ID 清理关联数据，不操作已有用户资料。若报告提示清理失败，需要检查本地数据库；强行结束进程时 finally 不保证执行。

## 固定题库和检查规则

题库在 `apps/server/src/evaluation-cases.ts`，版本 1.0。两份资料分别为合成的报销制度和请假流程。题库变化时应调整版本号，不能把不同题库的总通过率直接当成检索改善。

| 题目 | 要验证什么 |
| --- | --- |
| 报销材料有哪些 | 报销制度进入前五条，答案包含发票、审批记录并引用 |
| 消费后多久提交报销 | 命中制度，答案包含七天或等价数字表达并引用 |
| 报销最高额度 | 能找到相关制度，但不能编造金额，应说明资料不足 |
| 火星飞船燃料配方 | 没有匹配资料，应直接拒答且没有模型调用和用量 |
| 请假由谁审批 | 请假资料进入前五条；本轮不调用模型回答此题 |
| 买东西之后要在几日以内递交凭证 | 同义问法也应召回报销制度；本轮只测检索 |
| 跨用户访问 | 第二位用户不能检索第一位用户的资料，不能读写其会话 |

报销资料明确写有“本文未规定报销额度”，因此额度题只是较容易的拒答基线，尚未测试所有资料完全不提额度时的表现。题库没有覆盖长文分段、多份制度冲突、恶意文档指令、大量资料、多人共享或 PDF。

检索按前五条是否包含预期标题判断，并另外记录第一条是否正确。问答初筛检查完成状态、关键词、拒答特征、引用编号范围、来源快照和无资料时的调用次数。规则可能误判，例如含“资料不足”后仍编造金额也可能通过正则，必须读原文复核。合法的 `[1]` 也可能引用错误结论，编号检查不能替代语义检查。

## 本轮实际结果

- [离线报告：7/8 通过](evaluations/2026-10-09T07-31-55-295Z-offline.md)，模型调用 0 次。
- [真实报告：10/11 通过](evaluations/2026-10-09T07-32-17-911Z-live.md)，模型调用 3 次。
- 三次模型请求均 completed；材料回答 6282 ms，时限回答 7349 ms，额度拒答 6560 ms。无资料直接拒答为 5 ms。
- 类型检查、普通接口测试、数据库集成测试、生产构建均通过。

这两个分数是不同检查项的合计，不能称为模型准确率。真实模式包含六项检索、一项权限、四项问答初筛；离线模式只有六项检索、一项权限、一项无资料问答。

唯一失败是同义问法检索：题目使用“买东西、几日、递交凭证”，资料使用“消费、七天、提交报销”。中文二字词匹配没有发现关联。时限题还召回了无关的请假流程，说明检索精度也有改善空间。

发现效果失败时退出码为 1，npm 会显示命令失败；这表示本轮效果没有全部达到期望，不表示项目无法启动。打开对应报告定位失败项，不要修改题目的预期来隐藏失败。

代码助手已逐条对照本轮答案与资料：材料、时限的 `[1]` 对应原文，额度回答未给出金额，无资料回答直接说明不足。这个复核不代替用户人工验收，也不能证明模型对其他问题不会编造。请在真实报告旁逐题记录人工结论，特别检查每个引用是否支持对应事实。
