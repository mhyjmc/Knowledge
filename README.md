## 本地启动

要求 Node.js 20.19 或更新的受支持版本、npm 10 或更新版本。登录需要 PostgreSQL，当前不需要模型 API 密钥。请先按第二步文档启动数据库并运行迁移。

Windows 可以双击根目录的 start.cmd 启动，窗口会保留启动结果。也可以在 PowerShell 中依次执行：

```powershell
Set-Location D:\zhxzzz\team-knowledge-assistant
npm install
npm run dev
```

打开 http://127.0.0.1:5173 ，页面应显示“前后端已连接”。后端地址为 http://127.0.0.1:3001/api/health 。结束运行按 Ctrl+C。

项目已经运行时，再执行 npm run dev 会提示现有页面地址，无需再次启动。若提示端口占用但服务不完整，请检查原启动终端。不要直接双击 apps/web/index.html，也不要用静态文件服务器替代 npm run dev，否则无法使用开发代理。

```powershell
npm run typecheck
npm test
npm run build
```

分别进行 TypeScript 检查、接口测试、生产构建。构建产物位于 apps/web/dist 和 apps/server/dist。真实数据库测试需先启动 PostgreSQL，再运行 npm run test:db；生产部署配置见 [部署与演示](docs/12-部署与演示.md)，Docker 引擎尚待本机验收。

Windows 也可以双击 check.cmd 执行类型检查和接口测试，它会自动进入本项目目录并显示退出码；0 表示通过。遇到错误请保留完整报错文字。

```text
team-knowledge-assistant/
├── README.md              阅读入口
├── AGENTS.md              后续开发与中文文档更新约定
├── package.json           统一安装、启动、检查命令
├── package-lock.json      安装后生成，固定依赖版本
├── apps/
│   ├── web/               Vue 3 + TypeScript 前端
│   └── server/            Node.js + Fastify + TypeScript 后端
└── docs/                  中文项目与学习文档
```

效果评测：`npm run eval` 只使用本地数据库，不调用模型；`npm run eval:live` 最多顺序调用模型三次，可能产生费用，且不自动重试。结果保存到 `docs/evaluations/`。任何检查失败时命令返回退出码 1；最新离线评测全部通过，旧版同义问法失败基线仍保留。

本机服务端模型配置已完成并验证；浏览器文件导入、引用原文展示、整页刷新历史恢复、正文返回前停止生成和待办确认已通过。生产部署文件见 [部署与演示](docs/12-部署与演示.md)。新环境需要自行填写 .env 的数据库与模型配置，执行 `npm run db:migrate` 后启动后端。Docker Desktop 不可用时，可使用 `npm run db:local` 启动项目专属的本地 PostgreSQL，数据保存在 `.local-postgres/`。已有部分正文后的停止仍待验证。
